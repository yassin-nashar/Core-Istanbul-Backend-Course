Node.js · fs

Blocking

readFileSync يوقف تنفيذ الملف لين تخلص قراءة data.txt. السطر اللي بعده ما يشتغل إلا بعد ما ترجع القراءة.

الكود

import { readFileSync } from "node:fs";

console.log("1. Start");

readFileSync("data.txt", "utf8");

console.log("2. File loaded");
console.log("3. Continue working");

الناتج

1. Start
2. File loaded
3. Continue working

الترتيب من فوق لتحت: البداية، ثم تحميل الملف، ثم متابعة الشغل. الخيط وقف عند readFileSync وما كمل إلا بعده.
