# Reusable build prompt

Build a local-only Event Booking security-audit exercise and a matching secure instructor solution using Express, strict TypeScript/ESM, PostgreSQL, Prisma, Zod, JWT, and Argon2id. Models: User(USER/ADMIN), Event, Booking with unique user/event pair, and rotating hashed refresh tokens. Provide auth, event CRUD, booking CRUD, and own-profile endpoints, repeatable synthetic seed data, isolated databases, tests, Postman, READMEs, and an instructor guide. The audit version must remain functional but contain one controlled weakness in each of Authentication, RBAC, Ownership, JWT, Sensitive Data, Headers, and Rate Limiting; bind localhost, reject production, and never reveal answers in student materials. The solution must enforce the documented matrix, database ownership predicates, verified JWT claims, safe response selection, Helmet, deterministic configurable rate limiting, and 401/403/404/409/429 behavior. Do not add unrelated vulnerabilities, frontend, CORS/SQLi/XSS/CSRF exercises, secrets, or TODO answers.
