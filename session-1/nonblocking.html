Non-blocking

readFile يطلب القراءة ويرجع فوراً. السطر اللي بعده يشتغل قبل ما يوصل محتوى الملف، والنتيجة تنطبع جوا الـ callback.

الكود

import { readFile } from "node:fs";

console.log("1. Start");

readFile("data.txt", "utf8", (error) => {
  if (error) {
    console.error(error);
    return;
  }

  console.log("3. File loaded");
});

console.log("2. Continue working");

nonblocking-demo.mjs

الناتج

1. Start
2. Continue working
3. File loaded

«Continue working» انطبع قبل «File loaded»، لأن القراءة صارت بالخلفية والكود اللي بعدها ما استناها.
